# knowledge/career/

Job-search notes, target-role research, compensation benchmarks, and career-strategy artifacts.

Typical contents:

- `job-search/applications.md` — log of applications submitted, status, follow-ups.
- `job-search/prep/<company>-<date>.md` — interview prep packets, written by the `interview-prep` skill.
- `comp-benchmarks.md` — known comp data points (with sources) for roles you are targeting.
- `narrative/<theme>.md` — STAR stories or talking points you have rehearsed.

The `interview-prep` and `job-strategy` skills will look here first for existing context before generating new content.

## Privacy

This is one of the most sensitive directories in the knowledge base. Audit thoroughly before any public push.
